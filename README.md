# Purrfect Home (frontend)  
## Опис
Цей репозиторій створено для демонстрації фронтенду та його взаємодії з сервером вебсайту "Purrfect Home".  
На клієнті можна побачити вкладки "Коти" та "Заводчики". Там розташовуються оголошення та заводчики відповідно.  
Спочатку користувач бачить коротку інформацію, а при кліку на кота/заводчика отримує повну інформацію. (у тому числі список оголошень заводчика)  
Даний фронтенд не містить усього функціоналу, описаного в README та бекенді, оскільки його головна мета - показати, що фронтенд та бекенд можуть розвиватися незалежно та взаємодіяти за певними домовленостями.  

## Як запустити проєкт
### На бекенді:
1. Створити та активувати віртуальне середовище
```bash
python -m venv .venv

# for linux/macos
source .venv/bin/activate
# for Windows:
.venv\Scripts\activate
```

2. Встановити залежності  
```bash
pip install -r requirements.txt
```

3. Запустити міграції, щоб створити БД
```bash
python manage.py migrate
```

4. Запустити сервер  
```bash
python manage.py runserver
```

Базова адреса API: `http://127.0.0.1:8000/api` (не передбачена для роботи)  
До неї треба дописати ендпоїнт:  
- http://127.0.0.1:8000/api/cats
- http://127.0.0.1:8000/api/breeders
- http://127.0.0.1:8000/api/breeds

### На фронтенді:  
1. Запустити через окремий термінал (одночасно з бекендом)  
```bash
python -m http.server 5500
```

Сайт буде доступним за адресою http://localhost:5500

P.S. Фронтенд (html, css, js) було реалізовано за допомогою Claude, бо це не входить до вивчення у межах даного курсу.
